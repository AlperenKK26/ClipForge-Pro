# ClipForge-Pro
ClipForge Pro is a modern Python desktop app designed to download videos and audio from YouTube, TikTok, and Instagram. It supports full playlists, multi-posts, and crystal-clear 320 kbps MP3 extraction. Best of all, it encodes MP4s into edit-friendly H.264/AAC for seamless, glitch-free timeline playback in Adobe Premiere Pro with zero codec issues
